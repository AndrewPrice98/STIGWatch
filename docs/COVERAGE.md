# Coverage

Generated by `python -m stigwatch coverage --write`; CI fails if it is out of date. Every number comes from the check engine and the remediation generator.

- **Automated**: a declarative check reads collector facts for the rule.
- **full**: the check can return Open and Not a Finding. **partial**: only one of them (the other outcome is Not Reviewed). **evidence**: neither; it settles Not Applicable when a fact proves it, otherwise Not Reviewed with the facts shown.
- **Manual**: no check; the rule is Not Reviewed and the check text is shown.
- **Remediation**: rules whose fix can be generated (an Ansible task or a PowerShell step). Nothing is ever applied by STIGWatch.
